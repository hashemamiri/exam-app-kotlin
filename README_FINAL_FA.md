# مرحله ۱۰ و جمع‌بندی مهاجرت Native

## اضافه‌شده در این مرحله
- قرارداد دریافت نسخهٔ جدید برنامه
- Use Case قابل تست برای مقایسهٔ نسخهٔ نصب‌شده و نسخهٔ سرور
- ViewModel برای بخش «درباره / بروزرسانی» با یادداشت‌های فارسی
- نمونه تست واحد برای تثبیت جای تصویر روی A4
- GitHub Actions فارسی برای تست و ساخت APK با Gradle

## وضعیت مراحل
1. زیرساخت Compose و Navigation
2. Auth و OTP
3. آزمون دانش‌آموز
4. Room و آفلاین
5. آزمون‌ساز معلم
6. تصویر و چیدمان آزاد
7. A4 و PDF
8. تصحیح و گزارش
9. کلاس، تقویم و پرداخت
10. بروزرسانی، CI و تست

## کارهای ضروری پیش از انتشار واقعی
- افزودن Gradle Wrapper به مخزن
- تنظیم Supabase URL و anon key در secret یا local.properties
- پیاده‌سازی DTO/mapper همهٔ جدول‌ها
- اتصال Repositoryهای قراردادشده به Supabase
- افزودن تست‌های UI برای مسیرهای ورود، آزمون، تصویر و چاپ
- امضای release APK در CI با secretهای GitHub
- انتقال تدریجی مسیرها از WebView و تأیید رفتار هر feature
