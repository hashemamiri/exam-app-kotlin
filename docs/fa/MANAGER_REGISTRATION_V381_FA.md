# V38.1 — رفع خطای تبدیل حساب تازه به مدیر/معاون

## علت

در بعضی پروژه‌های قدیمی، trigger ساخت profile بلافاصله پس از OTP، حساب ایمیلی تازه
را موقتاً با `role=teacher` می‌سازد. RPC V36 فقط roleهای student/manager را برای
setup مدیر می‌پذیرفت و پیام «این حساب قابل تبدیل به مدیر/معاون نیست» می‌داد.

## اصلاح امن

profile موقت `teacher` فقط وقتی قابل تبدیل است که کاملاً خالی باشد:

- `teacher_id` نداشته باشد؛
- هیچ کلاس، آزمون یا دانش‌آموز ساخته‌شده نداشته باشد؛
- عضو active هیچ مدرسه‌ای نباشد؛
- خودش عضو کلاس دانش‌آموزی نباشد.

بنابراین ایمیل تازه عبور می‌کند، ولی حساب معلم واقعی دارای داده یا عضویت هرگز به
مدیر تبدیل نمی‌شود.

```text
SQL: sql/manual/SQL_NATIVE_MANAGER_REGISTRATION_V381_HOTFIX.sql
Edge/App/Secret/Dependency جدید: ندارد
پیش‌نیاز: SQL V36
```
