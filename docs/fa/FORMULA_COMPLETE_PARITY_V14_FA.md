# V14 — برابری کامل همهٔ قابلیت‌های فرمول `exam-system.html`

**تاریخ:** ۲۰۲۶-۰۸-۱۳

## هدف

تمام قابلیت‌های واقعی، پنهان و نیمه‌فعال بخش فرمول فایل مرجع به Native Kotlin منتقل شدند. باگ‌ها و محدودیت‌های مرجع عیناً کپی نشدند؛ برای هر مورد یک راهکار Native قابل استفاده پیاده‌سازی شد.

## قابلیت‌های قابل دسترسی

### حالت‌ها و ابزارها

- جعبه‌ای، تایپ سریع و گالری همیشه قابل انتخاب‌اند.
- عنوان، راهنما، Undo/Redo، Copy/Paste، Zoom، search، کد حرفه‌ای و footer پنهان نیستند.
- Smart Hub دارای دکمهٔ واقعی در بالای ویرایشگر است.
- بستن، انصراف، پاک‌کردن و درج همیشه در دسترس‌اند.

### Smart Hub کامل

- فرمول آخر؛
- preview نهایی یا متن خام؛
- علاقه‌مندی‌های شخصی و شش پیش‌فرض مرجع؛
- درس‌های ریاضی، هندسه، آمار، فیزیک و شیمی؛
- ۳۰ قالب؛
- کتابخانهٔ ترکیبی هر درس؛
- Quick Convert عادی و شیمی؛
- هشت مورد اخیر همراه حذف؛
- هشت بستهٔ امتحانی؛
- شش جفت دلیمتر؛
- هشت کلید درشت موبایل؛
- preview SVG جاری.

### ویرایش ساختاری

- خانه‌های SVG قابل لمس و رنگ فعال؛
- کسر، توان، زیرنویس، رادیکال فرجه‌دار، عدد مخلوط، limits، ماتریس، متن، accent و سطر تازه؛
- `/` تبدیل به کسر؛
- `^` و `_` ساختاری؛
- `*`/`×`, `÷`, `->`, `<-`؛
- جفت پرانتز و انتخاب جداگانهٔ باز/بسته؛
- Backspace امن بدون تخریب byteهای فرمان TeX؛
- چپ/راست خطی، بالا/پایین مکانی، Tab/Shift+Tab، Home/End؛
- Ctrl/Cmd+Z/Y/C/V، Enter و Escape؛
- auto-scroll افقی و عمودی خانهٔ فعال؛
- Undo/Redo تا ۸۰ حالت.

### Clipboard و Import

- Copy کد TeX بدون `$`؛
- Paste TeX دارای command؛
- حذف `$` بیرونی؛
- تبدیل متن طبیعی پیست‌شده؛
- paste چندکاراکتری با قواعد ساختاری؛
- جایگزینی امن مدل بدون قرارگرفتن cursor داخل نام command.

### مبدل تایپ طبیعی

- نمونه‌های مرجع؛
- کسر گروهی؛
- توان تودرتو `x^2^3 → x^{2^{3}}`؛
- توان و زیرنویس هم‌زمان؛
- روابط، فلش‌ها، ضرب، تقسیم و تقریب؛
- واژگان فارسی و انگلیسی؛
- اعداد فارسی، عربی و لاتین؛
- توابع، یونانی، بردار، حد، مجموع و انتگرال.

### شیمی اصلاح‌شده

```text
H2O      → H_{2}O
Fe3+     → Fe^{3+}
SO4 2-   → SO_{4}^{2-}
⇌        → \rightleftharpoons
```

باگ حذف backslash در مرجع برطرف شد.

### ماتریس

- presetهای کتابخانه؛
- picker واقعی ۱×۱ تا ۱۰×۱۰؛
- preview SVG؛
- `matrix`, `bmatrix`, `pmatrix`, `vmatrix`, `Bmatrix`, `Vmatrix`؛
- دلیمتر متناسب؛
- source range مستقل هر سلول؛
- ناوبری مکانی و Undo بر پایهٔ متن/selection، بدون باگ path مرجع.

### دلیمترها

- شش جفت آماده؛
- انتخاب مستقل سمت باز و بسته؛
- پرانتز، کروشه، آکولاد، قدرمطلق، کف و سقف؛
- SVG path کش‌پذیر؛
- درج در خانهٔ فعال.

### فرمان‌های تکمیلی renderer

علاوه بر کتابخانهٔ موجود:

```text
\sfrac / \nicefrac
\root
\underline
\widehat
\mbox
\quad / \qquad
Bmatrix / Vmatrix
```

فرمان ناشناخته کد خام نشان نمی‌دهد و fallback دیداری امن دارد.

### سابقه و علاقه‌مندی

- فرمول اخیر تا ۲۰ مورد؛
- نمایش هشت مورد در Smart Hub و گالری؛
- حذف تکی و پاک‌کردن همه؛
- نماد اخیر تا ۲۴؛
- علاقه‌مندی تا ۶۰؛
- long-press استاندارد Android همراه haptic؛
- دکمهٔ صریح علاقه‌مندی؛
- آخرین فرمول مستقل.

### گالری

- ۳۴ فرمول ثابت؛
- پنج گروه؛
- فرمول‌های اخیر در بالای گالری؛
- جست‌وجو؛
- انتخاب و انتقال به حالت جعبه‌ای.

### ویرایش فرمول قبلی

- `FormulaTextCodec` همهٔ `$...$`های سؤال را با range استخراج می‌کند.
- زیر متن سؤال، گزینه و هر دو ستون matching، preview با دکمهٔ «ویرایش» و «حذف» وجود دارد.
- ویرایشگر با TeX همان occurrence باز می‌شود.
- ذخیره فقط همان occurrence را جایگزین می‌کند.
- دیگر انتخاب دستی دقیق `$...$` لازم نیست.
- درج جدید همچنان در انتهای متن انجام می‌شود.

## امنیت

- هیچ JavaScript مرجع اجرا نمی‌شود.
- WebView وجود ندارد.
- TeX به AST بسته تبدیل می‌شود.
- SVG فقط از elementهای allowlist و متن XML-escaped ساخته می‌شود.
- URL، `href`, `src`, `script`, `foreignObject` و network در SVG وجود ندارد.
- Clipboard فقط با API سیستم و state داخلی کار می‌کند.
- هیچ Token، Header، Secret یا کلید واقعی اضافه نشده است.
