# V36 — زیرساخت مدیر/معاون و مدرسهٔ مستقل

## دامنه این مرحله

V36 فقط پایهٔ امن نقش، ثبت‌نام، tenant مدرسه و پوستهٔ مدیر را فعال می‌کند. مدیریت
واقعی دعوت/حذف معلم و مجوزهای دانش‌آموز/کلاس در V37 و انتقال کیف پول و آمار کامل
در V38 انجام می‌شود؛ UI به‌وضوح این مرحله‌بندی را اعلام می‌کند و عملیات نیمه‌امن
زودتر در دسترس نیست.

## ثبت‌نام

با لمس «ثبت‌نام»، صفحهٔ انتخاب زیر باز می‌شود:

```text
معلم | مدیر/معاون
```

مسیر معلم بدون تغییر اساسی ادامه دارد. مسیر مدیر/معاون:

1. نام و نام خانوادگی و ایمیل؛
2. OTP ایمیل Supabase؛
3. نام مدرسه، استان، شهر، نام کاربری و دو کادر رمز؛
4. RPC اتمیک `native_complete_manager_registration_v36`؛
5. ایجاد profile با role=`manager`، مدرسه و عضویت manager در یک transaction.

metadata امن Auth با `registration_role=manager` ذخیره می‌شود و
`native_my_registration_state_v1` نقش pending را برمی‌گرداند تا اگر برنامه میان
OTP و setup بسته شد، دوباره به setup مدیر برگردد. cache محلی نیز pending role را
ذخیره می‌کند ولی هیچ token یا رمز Auth را ذخیره نمی‌کند.

## tenant و RLS

SQL:

```text
supabase/migrations/20260815_native_school_manager_v36.sql
sql/manual/SQL_NATIVE_SCHOOL_MANAGER_V36.sql
```

جداول:

```text
schools
school_memberships
```

هر کاربر فقط یک عضویت active دارد. policy مدرسه فقط وقتی read می‌دهد که
`auth.uid()` عضو active همان مدرسه باشد. در V36 هیچ API برای دست‌کاری اعضای مدرسه
منتشر نشده است؛ این عملیات در V37 با RPC/Edge auditشده اضافه می‌شود.

## پوسته مدیر

- صفحهٔ شروع مدیر «معلم‌ها» است، نه تقویم.
- نوار پایین: منو، کیف پول، +، معلم‌ها، کارت‌ها.
- آیکن معلم‌ها از `Design69Icons.Students` استفاده می‌کند.
- `+` مستقیماً درخواست «معلم جدید» را به صفحه معلم‌ها می‌فرستد.
- کارت‌ها فقط صفحهٔ آمار پایهٔ مدرسه را باز می‌کند.
- منوی همبرگری مدیر فقط حساب، داده‌ها، تنظیمات و خروج دارد؛ تقویم و سربرگ ندارد.
- کیف پول مدیر در V36 صفحهٔ foundation دارد تا انتقال ناامن پیش از V38 فعال نشود.

## آمار پایه

`native_manager_school_summary_v36` نام مدرسه، استان، شهر و شمارش پایه را فقط برای
مدیر active همان مدرسه برمی‌گرداند. تعدادهای آموزشی کامل پس از ایجاد روابط V37
در V38 تکمیل می‌شوند.

## امنیت

- ثبت‌نام مدیر عمومی است اما فقط یک مدرسهٔ مستقل تازه می‌سازد.
- مدیر هیچ دسترسی به مدرسهٔ دیگر ندارد.
- password، service role و Auth token در SQL یا app ذخیره نمی‌شود.
- RLS روی هر دو جدول فعال است.
- مدیریت معلم، انتقال وجه و مجوزهای گسترده در V36 منتشر نشده‌اند.
