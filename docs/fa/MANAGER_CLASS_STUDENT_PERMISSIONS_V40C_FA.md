# V40C — مدیریت کلاس معلم و مجوزهای حذف دانش‌آموز

- آیکن ورود کارت معلم، مدیر را با هویت خودش وارد context کلاس‌های همان معلم می‌کند؛ impersonation وجود ندارد.
- مدیر کلاس برای معلم می‌سازد/حذف می‌کند، وارد کلاس می‌شود و دانش‌آموز مدرسه را اضافه/حذف می‌کند.
- همه دانش‌آموزان school_students در فهرست مدیر و معلم دیده می‌شوند؛ can_manage مشخص می‌کند چه کسی حساب را مدیریت کند.
- حذف در roster فقط class_members را حذف می‌کند. حذف کلاس فقط classes و membershipهای آن را حذف می‌کند؛ حساب دانش‌آموز باقی است.
- حذف حساب فقط از فهرست اصلی دانش‌آموزان و فقط با مجوز canManageAccount نمایش داده می‌شود.
