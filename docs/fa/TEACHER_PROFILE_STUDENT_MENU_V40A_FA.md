# V40A — پروفایل معلم و ساده‌سازی حساب/منوی دانش‌آموز

- نام نمایشی داخل کارت مستقل حفظ شد.
- کارت مشخصات معلم با نام، نام خانوادگی، کد پرسنلی و شماره تلفن اضافه شد.
- کد/تلفن اختیاری‌اند؛ کد حداکثر ۳۰ حرف/عدد و تلفن خالی یا 09xxxxxxxxx است.
- فقط خود معلم جزئیات را با RPC owner-only ذخیره می‌کند.
- دانش‌آموز کارت‌های تغییر نام کاربری، ایمیل و رمز را نمی‌بیند و ایمیل از مشخصاتش حذف شد.
- منوی دانش‌آموز دقیقاً سه ردیف است: آزمون/نتایج، تقویم/حساب، تنظیمات/خروج؛ داده‌ها حذف شد.
- دکمه‌های ظاهر و درباره وسط‌چین شدند.
